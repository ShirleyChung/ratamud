# 戰鬥迴圈系統重構

## 問題
之前的戰鬥系統中，NPC沒有在戰鬥中主動行動，導致戰鬥只有玩家單方面攻擊。

## 解決方案
實現回合制戰鬥迴圈系統：

### 1. 戰鬥流程
```
玩家攻擊 → 執行戰鬥回合 → NPC行動 → 回合結算 → 檢查戰鬥結束
```

### 2. 核心修改

#### 新增函數：`execute_combat_round()`
- 位置：`src/app.rs`
- 功能：
  - 遍歷所有戰鬥參與者（NPC）
  - 每個NPC有50%機率執行戰鬥技能
  - 隨機選擇 punch 或 kick 攻擊玩家
  - 回合結算：增加回合數，減少所有技能冷卻
  - 檢查戰鬥結束條件

#### 修改函數：`handle_combat_skill()`
- 玩家攻擊後調用 `execute_combat_round()`
- 確保每次玩家行動都觸發一個完整的戰鬥回合

#### 修改函數：`handle_escape()`
- 添加逃跑結算邏輯
- 給予參與者一半的經驗值
- 正確結束戰鬥狀態

### 3. 戰鬥回合機制

每次玩家執行攻擊技能時：
1. 玩家攻擊執行
2. **NPC回合**（新增）：
   - 遍歷所有敵對NPC
   - 50%機率決定是否行動
   - 隨機選擇技能攻擊玩家
3. 回合結算：
   - 回合數+1
   - 所有參與者技能冷卻-1
   - 通知玩家技能準備好
4. 檢查戰鬥結束條件

### 4. NPC行動邏輯

```rust
// 每個NPC有50%機率執行戰鬥指令
if rng.gen_bool(0.5) {
    // 隨機選擇戰鬥技能
    let skills = ["punch", "kick"];
    let skill_name = skills[rng.gen_range(0..skills.len())];
    
    // 執行NPC攻擊玩家
    execute_attack(skill_name, participant, "me", ...)?;
}
```

### 5. 逃跑機制

使用 `esc` 指令：
- 結算戰鬥（給予一半經驗值）
- 清除戰鬥狀態
- 允許玩家移動

## 測試方式

使用 `./test_combat_loop.sh` 查看測試指南，或手動測試：

1. 啟動遊戲：`cargo run`
2. 靠近NPC：`flyto 3,3`
3. 發起攻擊：`punch` 或 `kick`
4. 觀察NPC反擊（約50%機率出現）
5. 繼續戰鬥數回合
6. 逃離戰鬥：`esc`
7. 確認獲得經驗值

## 預期行為

### 戰鬥中
- ✅ 玩家攻擊後，NPC有機會立即反擊
- ✅ 每回合最多看到1-2次NPC攻擊（取決於隨機）
- ✅ 技能冷卻正常計算
- ✅ HP降低時自動結束戰鬥

### 逃跑
- ✅ 獲得 `回合數/2` 點經驗
- ✅ 戰鬥狀態清除
- ✅ 可以正常移動

## 技術細節

### 隨機性
- 使用 `rand::gen_bool(0.5)` 決定NPC是否行動
- 50%機率確保戰鬥不會太激烈或太無聊

### 回合結算時機
- 在所有NPC行動完成後
- 在檢查戰鬥結束之前
- 確保技能冷卻正確更新

### 戰鬥結束條件
- 玩家 HP ≤ 50%
- 任一NPC HP ≤ 50%
- 玩家使用 esc 逃跑

## 後續優化建議

1. **AI策略多樣化**：NPC可以根據HP、距離等因素選擇不同技能
2. **難度調整**：調整NPC行動機率（簡單30%、困難70%）
3. **技能選擇智能化**：優先使用冷卻完畢的技能
4. **多目標戰鬥**：支援同時與多個NPC戰鬥
5. **戰鬥日誌**：詳細記錄每回合的行動順序
